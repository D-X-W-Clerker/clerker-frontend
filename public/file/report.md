## 클로커 서비스 개발 과정 요약

![chunk_1](bllossom_diagram/mermaid/chunk_1.png)

**요약**:

클로커 서비스는 주제 선정부터 디자인 기획, CICD 구축 모델 성능 테스트까지 월별로 주요 단계를 거쳤습니다. 두 번의 중간 발표를 통해 교수님의 피드백을 반영하여 기능별 API 구현과 모델 성능 업그레이드, 서버 구축을 진행했습니다. 서비스 플로우는 Google 소셜 로그인으로 시작하여 회의 생성 페이지에서 일정 조율 기능을 통해 회의 일정을 잡을 수 있습니다.

## 회의 관리 시스템

![chunk_2](bllossom_diagram/mermaid/chunk_2.png)

**요약**:

회의 일정을 잡을 수 있는 페이지를 구현하였으며, 멤버들을 초대하고 관리할 수 있는 기능을 제공합니다. 회의 생성 시 Google 미트와 같은 URL이 발급되며, 이를 통해 참석을 요청하고 회의를 녹화할 수 있습니다. 녹화 후 오디오 파일을 모델 서버에 전송하여 영상을 랜더링하고, 이를 요약 페이지로 전송합니다.
